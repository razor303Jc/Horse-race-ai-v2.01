# Horse Race Handicapping AI

An advanced AI-powered system for horse race handicapping, prediction, and simulation using machine learning and Monte Carlo methods.

## 🏇 Features

- **Machine Learning Predictions**: Advanced ML models for race outcome prediction
- **Monte Carlo Simulations**: Statistical race simulations using confidence ranges and performance variability
- **Confidence Range Modeling**: Statistical uncertainty analysis with realistic performance distributions
- **Form & Rating Analysis**: Combined scoring system using historical form and official ratings
- **Real-time Analytics**: Performance tracking and trend analysis with betting insights
- **British All-Weather Racing**: Specialized focus on UK all-weather tracks with comprehensive data
- **RESTful API**: FastAPI-based backend for easy integration
- **Async Operations**: High-performance async database and API operations
- **Comprehensive Testing**: Full test suite with unit, integration, and ML tests

## 🛠️ Technology Stack

- **Backend**: Python 3.11+, FastAPI, SQLAlchemy (async)
- **Database**: PostgreSQL with TimescaleDB, Redis for caching
- **ML/AI**: TensorFlow, scikit-learn, Stable-Baselines3
- **Simulation**: NumPy, Monte Carlo methods with Numba optimization
- **Testing**: pytest, pytest-asyncio, pytest-cov
- **Development**: Black, flake8, pre-commit hooks

## 📚 API Documentation

Once the server is running, visit:

- **Interactive API docs**: http://localhost:8000/docs
- **ReDoc documentation**: http://localhost:8000/redoc
- **Health check**: http://localhost:8000/health

### Main Endpoints

- `GET /health` - System health check
- `GET /api/v1/races` - List all races
- `POST /api/v1/predictions` - Generate race predictions
- `POST /api/v1/simulations` - Run Monte Carlo simulations
- `GET /api/v1/analytics/horses/{id}` - Horse performance analytics

## 🎲 Monte Carlo Simulation Engine

The advanced Monte Carlo simulation engine provides realistic race modeling using:

- **Confidence Range Analysis**: Statistical uncertainty modeling for each horse's performance
- **Race Day Factors**: Dynamic variance including track conditions, distance effects, and random factors
- **Performance Distribution**: Normal distribution sampling within calculated confidence ranges
- **Betting Insights**: Overlay/underlay detection and value betting opportunities
- **Statistical Validation**: Win/place/show probabilities with accuracy tracking

### Key Features

- **Enhanced Realism**: Incorporates race day variability and luck factors
- **Large-Scale Simulation**: 25,000+ race simulations for accurate probability estimation
- **Performance Metrics**: Detailed analysis of simulation accuracy vs actual results
- **British All-Weather Focus**: Optimized for UK all-weather racing conditions

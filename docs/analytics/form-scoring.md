# 🏇 Form Scoring System

_Advanced form scoring with interactive analytics_

## Overview

Our comprehensive form scoring system evaluates horse performance using multiple weighted factors to provide accurate and reliable form ratings.

## Scoring Methodology

### Weighted Components

| Component            | Weight | Description                        |
| -------------------- | ------ | ---------------------------------- |
| **Win Rate**         | 40%    | Percentage of races won            |
| **Place Rate**       | 30%    | Percentage of top-3 finishes       |
| **Average Position** | 20%    | Consistency in finishing positions |
| **Prize Money**      | 10%    | Total earnings performance         |

### Scoring Scale

- **90-100**: Excellent form (Elite performers)
- **75-89**: Good form (Strong contenders)
- **60-74**: Average form (Consistent performers)
- **40-59**: Below average form (Inconsistent)
- **0-39**: Poor form (Struggling performers)

## Analysis Insights

### Key Findings

- Form scores correlate strongly with recent winning probability
- Consistency metrics (place rate) are often better predictors than raw win rate
- Prize money component helps identify class levels

### Usage Guidelines

- Use form scores as a primary filter for race analysis
- Combine with other metrics (speed, pace) for comprehensive evaluation
- Consider recent form trends over historical averages

## Technical Details

### Calculation Process

1. Raw performance data extraction
2. Statistical normalization (0-100 scale)
3. Weighted component combination
4. Grade classification assignment
5. Trend analysis and validation

### Update Frequency

- **Real-time**: During active racing periods
- **Daily**: Comprehensive recalculation at 02:00
- **Weekly**: Full historical reprocessing

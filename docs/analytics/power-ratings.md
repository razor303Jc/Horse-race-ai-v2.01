# ⚡ Power Ratings System

_Speed-based power ratings with comprehensive analysis_

## Overview

Our power ratings system evaluates horses based on speed performance, normalized across different courses and distances to provide accurate comparative ratings.

## Power Rating Methodology

### Core Metrics

- **Speed Ratings**: Distance/time calculations normalized to 0-100 scale
- **Course Adjustments**: Track-specific performance factors
- **Distance Scaling**: Proportional speed adjustments
- **Class Levels**: Performance within competitive grades

### Rating Classifications

| Rating Range | Classification | Description                |
| ------------ | -------------- | -------------------------- |
| **90-100**   | Elite          | Championship-level speed   |
| **75-89**    | Fast           | Above-average performers   |
| **50-74**    | Average        | Standard competitive speed |
| **25-49**    | Below Average  | Developing speed           |
| **0-24**     | Slow           | Entry-level performers     |

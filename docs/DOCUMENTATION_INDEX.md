## 📝 **File Organization Principles**

### **What's in Root:**

- **README.md** - Main project documentation
- **Configuration files** - docker-compose.yml, requirements.txt, etc.
- **Dockerfiles** - Container definitions
- **Core project files** - Makefile, pyproject.toml, etc.

### **What's in docs/:**

- **All markdown documentation** organized by purpose
- **Implementation plans** and technical specifications
- **Reports and analysis** results
- **User guides** and tutorials

### **What's NOT in Root:**

- ❌ Python scripts (moved to appropriate directories)
- ❌ Log files (moved to logs/)
- ❌ Documentation files (moved to docs/)
- ❌ Empty files (cleaned up)

## 🔄 **Recent Reorganization (August 2025)**

### **Files Moved:**

- **Python Scripts** → Organized into `tools/`, `docker/`, etc.
- **Documentation** → Organized into `docs/` subdirectories

### **Benefits:**
